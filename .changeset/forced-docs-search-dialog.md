The icons of the docs theme's search dialog keep showing in forced colors, such as a Windows contrast theme. They are masks, whose fill the browser paints in the page's color there, so the back button on a phone, the layout toggle and the reset button, which are their icon alone, could not be seen at all, and the magnifier of the field, the chevrons between the titles of a result and the arrows of the keys under the results were gone. Each is now drawn in the system's color of its text: a button's, a link's for a result's chevrons, and the page's. The reset button, disabled while the field is empty, is drawn as the system draws disabled text. The selected result, which the arrow keys move while the field keeps the focus, and the layout toggle while it shows the excerpts were marked by a color alone, which forced colors drop, so a keyboard user could not see which result the enter key opens, nor whether the toggle was on. The selected result now takes an edge in the system's color of a selection, heavier than the other results' edges, so it stands apart where a contrast theme makes that color close to a link's, and the toggle, while on, its icon in it. Out of forced colors nothing changes. A site on the docs theme takes this with no change of its own.
